# Credits

## Original QuickCD

QuickCD was created by **Creative Technology, Ltd.** in the early-to-mid 1990s as a companion application for Sound Blaster CD-ROM drives.

## Original Authors

- **DOS Version**: Written by PH Beh and Andy
- **Windows Version**: Written by Nigel Tan
- **DLLs**: CTCCW.DLL (CD Control for Windows) and CTRES.DLL (Resources)

## Open Source Reconstruction

This project is an educational, open-source reconstruction of QuickCD. It is not affiliated with or endorsed by Creative Labs or any of the original authors.

The goal is to preserve and study the engineering of classic hybrid DOS/Windows applications built with Open Watcom C and MCI.

## Era Context

QuickCD was designed for:
- IBM PC/AT and compatible systems
- Sound Blaster CD-ROM drives (or any MSCDEX-compatible drive)
- DOS 5.0+ with Windows 3.x
- 16-bit 286/386 protected mode
